# Idônea

Plataforma de gestão de projetos e vendas.

## Abrir

```bash
npm install
npm run dev
```

Acesse http://localhost:5173

## Módulos

- Projetos: lista, quadro Kanban, tarefas, subtarefas, anexos, comentários, menções e avisos
- Horas: timer, lançamento manual e relatório
- Vendas: funil, contatos, empresas, atividades e relatórios
- Importação: Asana e Clockify
- Comandos: texto e API `/api/gpt` com `X-Api-Key`
